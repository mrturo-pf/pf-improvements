# Migration note

This repository centralizes the PF improvement artifacts previously distributed
across `pf-base` and module repositories. The source repositories retain their Git
history and implementation documentation; this repository is the new canonical
home for improvement investigations, briefs, recommendations, plans, and generated
coordination context.

The existing GitHub Issues and Project remain the operational coordination layer.
Canonical Issue and Project links are updated after the repository's first release.
Historical metadata that was not present in source documents is marked explicitly as
unrecorded rather than inferred.
